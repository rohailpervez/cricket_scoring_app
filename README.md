#  Cricket Scoring App

This is a cross-platform (Android,  Web) cricket scoring application built with **Flutter** and **Firebase**.  
The app is designed for **HBS Team** to manage their matches, players, attendance, and yearly budget.

---

##  Features

- 📊 **Live Scoring Screen** – Scorer can update runs, wickets, overs in real-time.  
- 👤 **Player Profiles** – Each player has a profile with career stats (runs, wickets, averages, best figures).  
- ✅ **Attendance Tracking** – Player attendance sheet for every match.  
- 💰 **Budget Management** – Track annual funds and player contributions.  
- 🔥 **Firebase Integration** – Real-time sync of match data and stats across devices.  
- 🌐 **Cross-Platform** – Runs on **Android**,  and **Web**.

---

##  Tech Stack

- **Flutter** (Dart) – Cross-platform development  
- **Firebase Firestore** – Real-time database  
- **Firebase Auth** – Authentication (if enabled)  
- **GitHub** – Version control
